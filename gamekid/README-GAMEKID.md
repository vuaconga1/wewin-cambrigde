# GameKid

GameKid là bản sao độc lập của dự án WeWIN Education, chỉ công khai phần game Starter.

## Chạy dự án

1. Tạo các file môi trường từ file `.env.example` tương ứng.
2. Cài dependencies trong `backend` và `frontend` bằng `pnpm install`.
3. Chạy backend và frontend bằng `pnpm dev` tại từng thư mục.

Các thư mục `.git`, `node_modules`, `.next`, `dist` và các file chứa biến môi trường thật không được sao chép từ dự án gốc.
